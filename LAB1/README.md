## Overview
This lab contains the Software Requirements Specification for a Project Management System: a centralized, web-based platform for planning and managing projects. It supports creating projects, managing members, assigning and tracking tasks, deadlines, comments, notifications, dashboards, reports, user administration and audit logging.

## What the SRS covers
- **Introduction:** purpose, scope, audience, definitions
- **Overall Description:** product perspective, major functions, user roles, operating environment, constraints
- **External Interface Requirements:** user, hardware, software and communication interfaces
- **System Features:** functional requirements (PMS-F-###) with acceptance criteria and test case references
- **Non-Functional Requirements**, including security
- **Quality Attributes & Acceptance Tests**
- **System Models and Diagrams**
- **Requirements Traceability Matrix (RTM)**

## User Roles
- **Project Manager:** creates and manages projects, adds members, assigns tasks, monitors progress, generates reports
- **Team Member:** works on assigned tasks, updates status, adds comments
- **Administrator:** manages users and roles, monitors system activity, maintains configuration
- **Viewer:** read-only access to authorized project information and reports
